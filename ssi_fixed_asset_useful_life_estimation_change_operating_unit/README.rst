======================================================================
Fixed Asset Useful Life Estimation Change - Operating Unit Integration
======================================================================

This module integrates Operating Unit support into the Fixed Asset Useful Life Estimation Change module.
It allows fixed asset useful life estimation change documents to be scoped to a specific operating unit.
